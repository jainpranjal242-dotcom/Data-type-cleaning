# Data Type Cleaning Project
**Student:** Pranjal Jain

Includes a Jupyter Notebook, original CSV with incorrect types, PDF project report, and requirements.

Conversions:
- employee_id: text to integer
- salary: text to numeric
- joining_date: text to datetime
- name and department remain text

Install with `pip install -r requirements.txt`, then open the notebook in Jupyter or VS Code.
